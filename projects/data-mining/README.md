# Data Mining 📊

A compact data-mining workflow demonstrating preprocessing, exploratory analysis, clustering, and classification.

## Pipeline
1. Create/load tabular data
2. Clean missing values
3. Scale numeric features
4. Discover groups with K-Means
5. Train a Random Forest classifier
6. Print evaluation metrics

## Run
```bash
pip install -r requirements.txt
python main.py
```

The demo dataset is generated locally, so no external download is required.
