# Portfolio Projects 🚀

A curated collection of five portfolio implementations covering **Machine Learning, Data Mining, Computer/Embedded Systems, IoT and Arduino automation**.

Each project is organized as a small, reproducible codebase with documentation, tests where practical, diagrams, and clearly labeled benchmark information.

| Project | Focus | Verification |
|---|---|---|
| [Forest Fire Detection](./forest-fire-detection) | Python, scikit-learn, ML | Pytest + benchmark chart |
| [Smart Greenhouse](./smart-greenhouse) | Arduino, sensors, automation | Hardware test plan + architecture |
| [Arduino Radar](./arduino-radar) | Arduino, ultrasonic, serial visualization | Pytest protocol tests + hardware plan |
| [Data Mining](./data-mining) | Pandas, NumPy, scikit-learn | Pytest + benchmark chart |
| [Smart Trash Can](./smart-trash-can) | Arduino, IR sensor, servo | Hardware test plan + architecture |

## Engineering practices used

- Reproducible demo data where external datasets are unavailable
- Automated Python tests for deterministic logic
- Hardware test checklists for physical projects
- Architecture diagrams stored with each project
- Result charts that distinguish measured/generated demo results from real-world claims
- GitHub Actions CI for the Python test suites
- Project-specific READMEs with setup, structure, behavior and future work

> These are fresh portfolio implementations reconstructed from the project ideas discussed. They are not claims of preserving the user's original source code.
